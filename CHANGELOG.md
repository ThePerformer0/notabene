# Changelog

## [0.1.0] - 2026-02-20
### Version MVP Initiale
- **Fondations** : Modèles SQLAlchemy pour Sources (PDF/Web), Notes, Tags.
- **Managers** : Logique métier pour la gestion des documents et des sources web.
- **CLI** : Interface complète avec le thème personnalisé "The Performer".
- **Extraction** : Support de l'extraction automatique pour PDF (`pdfplumber`) et Web (`BeautifulSoup`).
- **Export** : Exportation vers BibTeX et Markdown.
- **Tests** : Suite de tests unitaires et d'intégration avec couverture de 74%.
- **Branding** : Logo ASCII personnalisé haute fidélité.
